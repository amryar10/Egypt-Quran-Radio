# Egypt Quran Radio By amryar10 — Android App

This archive contains the complete Android project with your custom icon, Play/Stop controls, sound-wave visualizer, 6 random startup colors, system Light/Dark theme, and **Developed by Eng. Amr Hamed** About button.

## Option 1: Build with Android Studio (Local)
1. Extract this ZIP folder.
2. Open **Android Studio** -> **Open** -> select the extracted folder.
3. Wait for Gradle sync to finish, then click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
4. Your APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

## Option 2: Build in the Cloud via GitHub (No Android Studio needed)
1. Extract this ZIP and upload all files (including the `.github` folder) to a new GitHub repository.
2. Open the **Actions** tab on GitHub and run **Build Android APK**.
3. Download `Egypt-Quran-Radio-APK` from the completed workflow run.
